# Texture provenance

| File | Source | Notes |
|---|---|---|
| `moon_albedo.jpg` | NASA SVS, LROC colour map (`lroc_color_poles_1k.jpg`) | Lunar Reconnaissance Orbiter Camera. NASA imagery, public domain. |
| `moon_displacement.jpg` | NASA SVS, LOLA elevation model (`ldem_3_8bit.jpg`) | Lunar Orbiter Laser Altimeter DEM, 8-bit. NASA imagery, public domain. |

Both are equirectangular, 1024x512, centred on 0 degrees longitude.

These are real lunar surface data, not artist renderings. That matters here for
the same reason the ephemeris does: the page shows correct libration, so over a
month the reader sees genuinely different parts of the limb rotate into view,
and a fictional surface would make that pointless.
